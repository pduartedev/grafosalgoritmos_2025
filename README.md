# Grafos e Algoritmos 2025

Repositório contendo implementações e exercícios práticos da disciplina de Grafos e Algoritmos desenvolvidos em 2025.

## 📋 Sobre o Projeto

Este repositório contém laboratórios e implementações de algoritmos fundamentais de teoria dos grafos, desenvolvidos em C++ com suporte de scripts Python para análise e visualização. 

## 🛠️ Tecnologias Utilizadas

- **C++** (90. 1%) - Implementação principal dos algoritmos
- **Makefile** (5.7%) - Sistema de build
- **Python** (4.2%) - Scripts auxiliares e análises

## 🚀 Como Compilar e Executar

### Pré-requisitos

- Compilador C++ (g++ recomendado)
- Make
- Python 3.x (opcional, para scripts auxiliares)

### Compilação

Para compilar qualquer laboratório, navegue até o diretório correspondente e execute:

```bash
cd LAB_0X
make
```

### Execução

Após a compilação, execute o binário gerado:

```bash
./main
```

### Limpeza

Para remover arquivos compilados:

```bash
make clean
```
